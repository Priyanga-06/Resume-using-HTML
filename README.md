# Resume-using-HTML

Personal Resume Website 🌐

This project is a personal resume website created using HTML and CSS. It presents my academic background, skills, projects, certificates, and contact details in a clean, structured, and visually appealing format.

📌 Project Overview

The resume website is designed as a single-page application that allows visitors to quickly understand my profile by scrolling through well-organized sections. Semantic HTML elements such as fieldset and legend are used to group content clearly, improving both readability and structure.

✨ Features

📄 Single-page resume layout

🎨 Clean and professional UI with soft color themes

🧩 Well-structured sections using fieldset and legend

🖼️ Circular profile image with styled border

📚 Clear separation of content using lists and headings

💻 Responsive and readable on different screen sizes

🛠️ Technologies Used

HTML5 – Structure and semantic elements

CSS3 – Styling, layout, colors, and spacing

🧱 Website Sections

About Me
Brief introduction highlighting my background, interests, and personality.

Education
Details of my B.Tech in Artificial Intelligence & Machine Learning.

Skills
Technical and soft skills presented using unordered lists.

Languages
Languages known and proficiency levels.

Certificates
List of certifications completed from recognized platforms.

Projects
Mini projects displayed using styled containers:

Voice-Based Assistant

Handwritten Digit Recognition

Contact Details
Phone number, email ID, GitHub, and LinkedIn links with clickable navigation.

🎯 Purpose of the Project

The main objective of this project is to:

Create a digital resume that is easy to share and access

Apply HTML and CSS concepts in a real-world scenario

Present personal and academic details in a professional manner

Serve as a foundation for future portfolio enhancements
